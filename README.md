# LocalSound Backend

Backend для музыкального приложения LocalSound.

## Дока
[flow скачивания песни по URL](docs/song-download-flow.md)

## Стек

- Java 25
- Spring Boot
- Gradle
- PostgreSQL
- Docker
- Docker Compose
- yt-dlp
- FFmpeg

## Возможности

- Загрузка аудио по URL
- Обработка и конвертация аудио
- Временное хранение загруженных файлов
- REST API для работы с загрузками
